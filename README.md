# Frontend Mentor - Mortgage Repayment Calculator

## 🤖 Visão Geral

Esta é uma solução para o desafio [Mortgage repayment calculator no Frontend Mentor](https://www.frontendmentor.io/challenges/mortgage-repayment-calculator-Galx1LXK73).

<br>

![preview](./.github/preview.jpg)

<br>

## 📚 Descrição

Uma calculadora de amortização de hipoteca que permite aos usuários inserir o valor da hipoteca, o prazo, a taxa de juros e escolher entre os tipos de hipoteca: amortização ou apenas juros. A calculadora então exibe os pagamentos mensais e o valor total a ser pago ao longo do prazo.

<br>

## ⚙️ Funcionalidades

- Validação de entrada para valor da hipoteca, prazo e taxa de juros
- Tratamento de erros e mensagens amigáveis ao usuário
- Suporte para dois tipos de hipoteca: Amortização e Apenas Juros
- Funcionalidade para limpar todas as entradas
- Design responsivo para mobile e desktop
